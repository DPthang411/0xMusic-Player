# 0xMusic-Player
My first largest project yet, still some rookie mistakes but it works for my need!

# How to use
Create "0xMusic_config.txt" and add your 1 path which is your music folder to it.<br/>
Optional: if you want to add song arts then make sure files' name is the same as your song files.

# Constraints 
only support .mp3 for songs and .jpg for arts.<br/>
song art files have to have the same name as song files.
